## 📌 簡報與網頁特色

本專案將 **2026 諾貝爾生理醫學獎：光遺傳學（Optogenetics）** 30 頁精華教學簡報，製作為具備「左圖右文、逐頁口語朗讀、自動播放」功能的互動式線上有聲教學網頁。

### 🌟 核心功能
1. **左圖右文完美版面**：左側 66% 投影片原圖，右側 33% 精煉口語導讀講稿。
2. **Web Speech API 語音朗讀**：內建臺灣國語語音朗讀（預設 Google 國語 臺灣），支援語速與音調微調。
3. **無縫自動播放**：支援「朗讀完才換頁」與「固定秒數」兩種自動播放模式。
4. **全螢幕沉浸式放映（F 鍵）**：適合課堂現場教學與公開觀課投影。
5. **膠卷縮圖與快速跳頁**：底部 Filmstrip 膠卷導覽與輸入頁碼跳頁。
6. **響應式與雙色主題**：支援手機與平板上下排列瀏覽，內建深色／淺色切換。
