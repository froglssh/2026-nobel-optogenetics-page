## 📌 專案簡介

本專案為 **2026 諾貝爾生理醫學獎：光遺傳學（Optogenetics）** 的獨立線上教學網頁，完整整合高中生物學科知識點、諾貝爾獎科學史、核心實驗邏輯與探究評量。

### 🌟 核心特色
- **得獎者與科學接力**：Peter Hegemann（大膽假說）、Georg Nagel（跨物種驗證）、Karl Deisseroth（工程化應用）。
- **高中生物知識串接**：接軌翰林版高中生物課程（膜電位、全有全無律、啟動子與細胞專一性表現）。
- **因果推理與探究實作**：以癲癇動物模型與視網膜修復臨床實例，引導學生辨析「充分性」與「必要性」的實驗控制邏輯。
- **生命倫理思辨**：從大腦記憶操控到 PTSD 治療，引導學生探討科技發展與人體倫理界線。
