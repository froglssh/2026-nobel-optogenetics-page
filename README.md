## 📌 專案特色

本專案將 **2026 諾貝爾生理醫學獎：光遺傳學（Optogenetics）** 整合為套件式的線上互動教學網站，包含：

1. **📖 互動式教學網頁（首頁 `index.html`）**：
   - 完整收錄 2026 諾貝爾得獎者（Peter Hegemann、Georg Nagel、Karl Deisseroth）與得獎理由。
   - 涵蓋核心概念地圖、分子機制、實驗數據解讀與倫理思辨。
   - 響應式佈局，完美支援電腦與行動裝置閱讀。

2. **🎙️ 30 頁逐頁有聲簡報網頁（`簡報網頁/`）**：
   - 左側 66% 呈現 16:9 高解析投影片圖檔。
   - 右側 33% 呈現林獻升老師逐頁口語導讀講稿。
   - 內建 Web Speech API 語音朗讀（臺灣國語）、自動播放、全螢幕放映（F 鍵）與膠卷跳頁。
